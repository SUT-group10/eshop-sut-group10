# E-04 — Phân tích thủ công của Vượng

> Bản phân tích cart tại thư mục gốc thuộc **thí nghiệm v1 — cart**. Thời lượng 20 phút và việc phân tích trước Sol chỉ áp dụng bộ v1; file phân tích gốc được giữ nguyên. [Protocol v2 hiện hành](../../experiments/order-history-protocol.md).

[phan-tich-vuong.md](phan-tich-vuong.md) là bản phân tích do Nguyễn Khắc Vượng thực hiện trên [bộ dữ liệu E-05](../E-05/participant-input.zip).

Thời lượng hoàn thiện: **20 phút**. Vượng hoàn thiện bản phân tích trước khi xem output Codex GPT-6.1 Sol. Tài liệu gồm kết quả 10 lượt, ba giả thuyết có dẫn chứng, ba bước kiểm tra và mức chắc chắn.

[SHA256SUMS](SHA256SUMS) lưu checksum bản phân tích và tài liệu kèm theo. Phần so sánh người–AI được lưu tại [E-08](../E-08/AI_vs_Human_Triage.md).
